# Pokédex 

Uma Pokédex interativa desenvolvida com HTML, CSS e JavaScript. O projeto permite explorar informações dos Pokémon por meio de uma interface simples e intuitiva.

## Objetivo 

O objetivo do projeto foi praticar e aprimorar conhecimentos em desenvolvimento web, lógica de programação, manipulação do DOM e construção de interfaces interativas.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Aprendizados

- Estruturação de páginas com HTML.
- Estilização e organização visual com CSS.
- Manipulação do DOM com JavaScript.
- Desenvolvimento de funcionalidades interativas.
